# v0.1.0-interview

Interview-oriented evidence release for OmniSell, an Amazon operations control tower with bounded AI Advisors.

## Highlights

- Four bounded Advisors: Operations Brief, Customer Case, Listing Optimization, and Reconciliation.
- Deterministic ownership of money, inventory, permissions, policy, approval, and state transitions.
- Strict Pydantic/JSON Schema Agent Runtime with evidence, context, token, cost, timeout, repair, failover, citation, and freshness controls.
- Approval-safe manual execution using immutable plans, action hashes, independent or dual approval, idempotency, audit, and recovery semantics.
- PostgreSQL RLS, four-persona OIDC E2E, Alembic migration gates, SBOM, Trivy, and Gitleaks.

## Known boundaries

- Golden Mock data is synthetic, not verified Amazon data.
- Real Amazon writes remain blocked under `read_only_pilot`.
- Real-provider quality remains `no-go / not_verified`. A controlled 30-50 case batch is the calibration stage; the implemented evaluator requires at least 25 normal and 5 adversarial cases per Advisor (120 total) before the sample-size gate is met, followed by named operator review.
- This release is interview evidence, not a production-readiness declaration.
